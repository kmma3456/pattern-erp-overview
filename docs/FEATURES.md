# 기능 상세

업무 ERP 화면 기준으로 정리했습니다.

---

## 1. 홈 (대시보드)

로그인 후 첫 화면입니다.

- 이번 달 매출, 승인 대기(연차·전표) 건수
- 출력/출고 현황
- **거래내역 미반영** 업체 — 전월 매출취합을 아직 보내지 않은 거래처
- 실장 이상은 미반영 업체를 골라 거래내역 화면으로 바로 이동

---

## 2. 거래내역관리

ERP의 중심 화면입니다.

### 입력 · 수정

- 거래 등록/수정 모달 (업체, 담당자, 품목, 단가, 작업 내역, 출고 관련 금액)
- 리스트에서 수량·단가 관련 항목 인라인 수정
- 계산서 / 입금 / 단가입력 플래그

### 필터

- **거래처** 엑셀형 다중 선택
  - 아무것도 안 고르면 `전체(N개)`
  - N은 **다른 필터까지 반영된 업체 수** (기간, 담당자, 입금, 단가, 계산서, 담당자명 등)
  - 필터를 바꿀 때마다 N이 다시 계산됩니다
  - 여러 곳을 고르면 `3개 선택`
- 기간 From/To, 담당자, 단가입력, 계산서, 입금
- 체크 컬럼 표시 + 체크/미체크 필터

### 매출취합 보내기 (실장 이상)

- 현재 필터 조건의 거래를 엑셀로 출력
- 거래처 미선택 → 업체별 파일 + ZIP
- 거래처 1곳 → 단일 엑셀
- 담당자 기준이면 한 시트에 행을 늘려 기록 (40건 초과 대응)
- 보내기 시 마일리지 사용 처리 (잔액 · 공급가 한도, 기간 중복 차감 방지)

---

## 3. 거래업체관리

- 업체 마스터 (대표자, 연락처, 업태/종목, 담당 직원)
- 미수금, 마일리지 잔액 · 적립률
- SMS 수신 번호 (최대 4개)
- 사업자등록증 이미지

---

## 4. 출력관리

출력 의뢰를 거래와 연결해 기록합니다.

- 출력 건 등록, 진행 상태
- 출고·포장 완료 시 연동 메시지 큐로 전달 가능

---

## 5. 출퇴근관리

- 날짜별 출근/퇴근 시각, 주간 근무시간
- 사이드바에서 오늘 출퇴근 버튼
- **지오펜스**: 지점 좌표 + 반경 밖에서 체크 불가 (`.env`로 좌표·반경 조정)

---

## 6. 연차관리

- 직원: 내 연차 신청, 상단에 발생/사용/잔여
- 실장·대표: 전체 신청 목록 + 달력, 승인/반려
- **반차 0.5일**, 기간 연차는 **평일만 차감** (토·일·공휴일 제외)
- 잔여 연차는 사용자관리의 `잔여/부여`와 같은 계산

예: 7/30 ~ 8/5 신청이어도 주말이 끼면 7일이 아니라 5일만 빠집니다.

---

## 7. 내역서관리

- 복지내역서, 지출결의서 신청
- 영수증 이미지 첨부
- 신청자 서명 → 실장/대표 결재 서명
- 엑셀/PDF 출력

---

## 8. 연동메세지관리

출고 완료, 포장 완료 등 이벤트 SMS.

| Provider | 용도 |
| --- | --- |
| MOCK | 로컬 시뮬레이션 |
| ALIGO | 알리고 |
| SOLAPI | 솔라피 |
| NCP_SENS | 네이버 클라우드 SENS |
| WEBHOOK | 외부 게이트웨이 |

발송 전 보류/취소, 실패 재시도 큐를 둡니다.

---

## 9. 사내게시판

공지·업무 공유용 게시글. 로그인 사용자만 접근합니다.

---

## 10. 사용자관리 · 백업 (대표)

- 직원 계정, 직급, 지점, 로그인 아이디
- 연도별 **연차 부여** → 리스트에 `7.5/15` 형태 잔여/부여
- 서명 이미지
- 데이터 백업 화면

---

## 업무 흐름 예시

**월말 매출 보내기**

1. 기간을 해당 월로 맞춤 → 거래처에 `전체(87개)`가 보임
2. 미입금만 보면 입금여부 필터 → 업체 수가 줄어듦
3. 실장이 매출취합 보내기 → ZIP + 마일리지 차감
4. 이미 보낸 기간의 업체는 중복 차감하지 않음

**연차**

1. 직원이 반차/연차 신청 (달력에서 공휴일 포함 구간 선택 가능)
2. 서버가 근무일만 일수로 계산
3. 실장 승인 시 잔여 연차 차감
4. 직원 연차관리 상단 숫자 = 사용자관리의 잔여와 동일
